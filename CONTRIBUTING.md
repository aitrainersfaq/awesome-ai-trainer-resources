# Contributing

Thanks for helping improve this list.

## Guidelines

- Add only free, public resources that help people doing or starting AI training and data annotation work.
- Link to the official page. No affiliate, referral or tracking links.
- Check the link works before you submit.
- Use this format: `[Name](https://link) - Short description.`
- Keep descriptions short and factual. No hype.
- Add one resource per pull request, in the most fitting section.
- Paid courses, job ads and pages that ask for payment to apply will not be accepted.

## Reporting a problem

Open an issue if a link is broken, a platform has closed, or a resource looks unsafe.

By contributing, you agree your contribution is released under [CC0 1.0](LICENSE).
